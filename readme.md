Вариант 9 Тема «Музыкант и звукорежиссёр» (релизы и оборудование) Flex-карточки:
«Мои релизы» (сингл/альбом, год, жанр, обложка) Grid-дашборд: «Студийное
оборудование» (фото устройства, название, назначение – 2 строки по 3 блока)
Адаптивность: карточки – 1/2/4; Grid – на мобильном 1, на планшете 2, на десктопе 3
колонки В семантике – <time datetime=""> для года релиза

`indexhtml` — разметка персональной страницы с формой, внутренними стилями списка и подписью к фото.
`stylecss` — таблица стилей с анимацией `@keyframes shake` , переменными темы и разметкой двухколоночной сетки

**Навигационное меню (`nav-div`):** Адаптивная горизонтальная панель навигации, использующая распределение элементов через `justify-content: space-between`  
**Карточки «Мои релизы» (`releases-div`):** Список из 4 карточек релизов. Для переноса элементов используется свойство `flex-wrap: wrap`

**Дашборд «Студийное оборудование» (`equipment-div `):** Модульная сетка для отображения 6 студийных устройств. По умолчанию на десктопе выстраивается в ровную структуру из 2 строк по 3 блока.

Вёрстка полностью адаптивна, не имеет горизонтальной полосы прокрутки и корректно перестраивается под разные экраны  :
**Десктоп (по умолчанию):** 4 Flex-карточки релиза в ряд   | 3 колонки Grid-оборудования  
**Планшет (до `992px`):** 2 Flex-карточки релиза в ряд   | 2 колонки Grid-оборудования  
**Мобильные устройства (до `576px`):** 1 Flex-карточка в ряд   | 1 колонка Grid-оборудования   Навигационное меню перестраивается в вертикальную стопку  

Каждая Flex-карточка обернута в семантически верный тег карточки (`<article>`)
Для разметки года выпуска музыкальных релизов применен строгий семантический тег `<time datetime="YYYY">`
