Вариант 9. Тема «Музыкант и звукорежиссёр» (громкость треков) Данные: массив из
5–7 чисел – громкость треков в дБ (например, 70–110). Логика: фильтрация – треки > 90
дБ. Цикл – тихие треки (≤ 75 дБ) и их количество. Функции: максимум, фильтрация,
сумма. Вывод: alert – «Средняя громкость – X дБ, Y треков – громкие». Console –
количество тихих треков и их средняя громкость. Доп.: если максимум ≥ 105 дБ, консоль
– «Такая громкость может повредить слух – используйте наушники с ограничением»

* `index.html` — основной документ страницы, содержащий семантическую разметку контента и встроенные CSS-стили в блоке `<head>`.
* `script.js` — скрипт логики, реализующий математический анализ уровней громкости треков.

### Алгоритм и логика работы скрипта:
1. **Функции:** Самостоятельная реализация базовых алгоритмов перебора (без использования встроенных методов массивов):
   * `findMaxVolume(arr)` — поиск максимального уровня громкости.
   * `filterLoudTracks(arr)` — фильтрация элементов, превышающих пороговое значение.
   * `calculateSum(arr)` — подсчёт суммы всех элементов массива.
2. **Фильтрация:** Выделение треков с громкостью `> 90 дБ` (громкие треки).
3. **Циклы и условия:** Подсчёт количества тихих треков (`≤ 75 дБ`) и вычисление их средней громкости с помощью классического цикла `for` и разветвленного условия `if/else`
4. **Безопасность:** Проверка пиковой громкости. Если максимум `≥ 105 дБ`, в консоль выводится предупреждение о защите слуха.
