Вариант 9. Тема «Музыкант и звукорежиссёр» (визуализация звука)
Используйте псевдоэлементы ::before и ::after для создания «визуальных волн» рядом с
названиями проектов. При :hover меняйте цвет волн и добавляйте лёгкое дрожание
(animation: shake). При :active на кнопке уменьшайте её масштаб на 2%. В переменных:
основной – тёмно-синий, акцент – фиолетовый. Inline-стиль: display: flex для контейнера
формы. Внутренний блок: стили для маркированного списка навыков (форма маркеров).
