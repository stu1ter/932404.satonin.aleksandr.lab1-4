Вариант 9. Тема «Музыкант и звукорежиссёр» (визуализация звука)
Используйте псевдоэлементы ::before и ::after для создания «визуальных волн» рядом с
названиями проектов. При :hover меняйте цвет волн и добавляйте лёгкое дрожание
(animation: shake). При :active на кнопке уменьшайте её масштаб на 2%. В переменных:
основной – тёмно-синий, акцент – фиолетовый. Inline-стиль: display: flex для контейнера
формы. Внутренний блок: стили для маркированного списка навыков (форма маркеров).

`index.html` — разметка персональной страницы с формой, внутренними стилями списка и подписью к фото.
`style.css` — таблица стилей с анимацией `@keyframes shake`, переменными темы и разметкой двухколоночной сетки.

Внешний CSS (`style.css`): Содержит основную логику оформления, сетки (CSS Grid/Flexbox) и анимации.
Внутренний блок `<style>`: Размещен в `<head>` документа `index.html`. Отвечает за изменение формы маркеров маркированного списка навыков (`list-style-type: disclosure-closed`).
Inline-стиль: Применен к тегу `<form>` для настройки контейнера (`style="display: flex; flex-direction: column; gap: 15px;"`).
CSS переменные (`:root`): Реализованы глобальные цвета интерфейса. В качестве основного выбран тёмно-синий (`#0d0b18` / `#161233`), в качестве акцента — фиолетовый (`#a29bfe`).
В коде наглядно продемонстрирована работа с позиционированием типов `static`, `relative` и `absolute`.
Состояния элементов: Настроены и проверены псевдоклассы `:hover`, `:active`, `:focus` и `:visited`.
